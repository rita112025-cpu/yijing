# 易經起卦

一個純前端的易經起卦小工具，使用三枚硬幣法產生六爻，顯示本卦、變爻與之卦，並整理成可複製給 AI 解讀的文字格式。

主檔案：`yijing.html`

## 功能

- 三枚硬幣法起卦，逐爻產生 6、7、8、9。
- 顯示本卦、卦序、卦名、上下卦與卦象符號。
- 自動標示老陰、老陽等變爻。
- 有變爻時顯示之卦；六爻皆不變時只顯示本卦。
- 內建 64 卦資料表與白話摘要。
- 可輸入問題，並產生 AI 可讀的解讀提示詞。
- 所有運算都在瀏覽器本機完成，不會自動送出資料。

## 使用方式

直接用瀏覽器開啟 `yijing.html`。

1. 在問題欄輸入想問的事情。
2. 點選「起卦」。
3. 閱讀本卦、變爻與之卦。
4. 需要 AI 協助解讀時，複製頁面產生的提示詞。

## 資料與驗證

`yijing.html` 內含以下資料與檢查邏輯：

- 八卦查表：依六爻二進位字串計算上下卦。
- 六十四卦查表：包含卦序、卦名、白話摘要與行動提示。
- Canonical 對照表：用獨立 64 卦表檢查卦序與卦名。
- 結構檢查：確認 64 卦筆數、卦序唯一、二進位代碼合法、資料無缺漏。
- AI 提示詞案例檢查：確認產生文字包含本卦、變爻、之卦與必要提醒。

開發時可在瀏覽器 Console 查看檢查輸出。
